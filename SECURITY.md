# Security policy

## Report a vulnerability

Please **do not open a public issue** for an exploitable vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/DineshDhanoki/Lumiqe/security/advisories/new) when available. If it is not enabled, contact the repository owner through their [GitHub profile](https://github.com/DineshDhanoki) and ask for a private reporting channel without including exploit details in a public comment.

Provide the affected component, reproduction steps, impact, and a suggested fix if you have one. Please avoid testing against other users' accounts or the hosted service without permission. We will acknowledge reports and coordinate a fix and disclosure with the reporter.

Only the latest `main` branch is actively maintained. We do not currently promise a fixed response or patch timeline.
